# Security policy

OES-Resilience is a research benchmark that runs on synthetic data. It does not process personal data and does not open network connections. It does read and write files under the output directory you choose, and `--plugins` imports third-party detector packages that you installed yourself. Only install plugins you trust.

## Supported versions

Only the latest release, and the `main` branch, receive fixes.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Contact the maintainer, Jean-François Brisson, privately via the contact details on the GitHub profile (https://github.com/sparkainlp-x) or the website (https://sparkainlpx.xyz). Please include:

- the affected version or commit;
- steps to reproduce; and
- the impact you expect.

You should get an acknowledgement within 7 days. Fixes are released as a new version and noted in the CHANGELOG.
